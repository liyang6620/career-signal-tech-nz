# 设计参考（Signal 风格的来源）

研究的网站，以及每个网站值得借鉴、或者要避开的地方。截图只用于内部研究，没有提交到仓库。

| 网站 | 为什么有"设计感" | 借鉴到 Signal 的地方 |
| --- | --- | --- |
| [Ramp](https://ramp.com/) | 米白底、近黑字，只用一种强调色；大号无衬线标题；数据用等宽小字，底部还有实时数字条 | 纸白 + 墨黑的底色；只保留一种品牌色；等宽小字做数据标签 |
| [Welcome to the Jungle](https://www.welcometothejungle.com/en) | 求职平台。整片铺满一种品牌色（黄），配粗壮的展示字体，品牌一眼就能认出来 | 品牌色要敢于整块铺开（落地页的数据条、概览页的指标区），不只是画细条 |
| [The Pudding](https://pudding.cool/) | 数据新闻。字体有个性，颜色大块铺色，日期和编号用等宽字 | 标题字体要有性格；数字要大 |
| [Cosmos](https://www.cosmos.so/) | 暖灰底，字距很紧的怪诞体标题，几乎没有装饰 | 标题收紧字距（-0.035em），少装饰 |
| [Linear](https://linear.app/) | 深色界面，排版克制 | 只作对照：这种风格已经被大量模仿，所以没有采用深色 |
| [Wellfound](https://wellfound.com/) | 求职平台，品红色加斜体 | 反面参考：渐变、浮动气泡、全大写字距标签，正是常见的"AI 模板"特征 |
| [SEEK](https://www.seek.co.nz/) | 新西兰本地求职网站的基准 | 用来确认我们不要做成招聘列表网站 |

## 由此得出的 Signal 规则

- **底色**：纸白 `#f2f1ec`，字和分隔线用墨黑 `#0e0e0e`。不用海军蓝，不用渐变，不加阴影（落地页预览卡的硬投影除外）。
- **只有一个品牌色：群青 `#2f2fe6`**，同时表示"雇主需求"。它会整块铺开：概览页的指标区、落地页的市场数据条、导航当前页的下划线。
- **另外两种语义色**：证据用绿 `#0f8a5f`，缺口用朱红 `#f04a23`。
- **字体**：标题用 Bricolage Grotesque 800，字距收紧；正文用 IBM Plex Sans；数据标签、表头、上下文行用 IBM Plex Mono。全部本地托管，SIL OFL 许可。
- **结构**：区块用 2px 黑色顶线分隔，不再用白底圆角卡片。必须是方块的地方（岗位卡、路径卡、职位卡）一律直角；选中状态是黑底反白。
- **数字**：关键数字放大，比如概览页的 82 是 112px，显示成粗黑的展示字。
